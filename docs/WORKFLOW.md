# 开发与调试工作流

本文档定义了芦笋分级系统的标准化开发、部署和现场调试流程。

## 1. 软硬件环境
- **开发机**：安装有 Android SDK 和 Python 环境。(详见 [ENVIRONMENT_SETUP.md](ENVIRONMENT_SETUP.md))
- **目标设备**：Android 手机（需开启 USB 调试模式）。
- **硬件现场**：包含两个 ARUCO 标记（ID 10 和 42），间距 500mm。

## 2. 标准工作流

### 第一步：代码开发
- **Android 代码**：源码位于 `src/android`。主要处理 UI、摄像头采集和日志输出。
- **算法代码**：源码位于 `src/vision`。处理图像分析逻辑。
  > **注意**：算法逻辑更新后，需同步更新至 Android 工程的相关模块中。

### 第二步：构建与部署
1. 确保手机已通过 USB 连接。
2. 在项目根目录（或 `src/android` 目录）运行构建命令：
   ```bash
   ./gradlew installDebug
   ```
3. 应用将自动安装并启动至手机。

### 第三步：现场观察与调试
1. 将手机固定在拍摄支架上。
2. 在应用预览界面确认：
   - 画面清晰，无明显遮挡。
   - 两个 ARUCO 标记（ID 10, 42）处于视野内且被正确识别。
   - 芦笋大致处于两个标记确定的直线平行位置。

### 第四步：日志分析与优化
1. 使用 `adb logcat` 获取实时运行日志：
   ```bash
   adb logcat -s AsparagusClassifier
   ```
2. 分析日志输出的分级结果、直径数据和错误信息。
3. 根据日志反馈调整 `src/vision` 中的算法参数或 `src/android` 中的 UI 交互。

## 3. 故障排查
- **无法识别标记**：检查环境光照，确保标记未反光且平整。
- **测量数据漂移**：检查手机是否晃动，确保透视变换基准稳定。
- **部署失败**：检查 `adb devices` 是否能识别到设备。
