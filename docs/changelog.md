# 更新日志

## 版本 1.1 (基于实际环境数据更新)

### 更新日期
2024年

### 主要变更

#### 芦笋生物学特性文档更新
- **物理长度范围**：从15-30厘米更新为30-60厘米（基于实际生长环境）
- **有效长度范围**：从10-20厘米更新为15-35厘米（绿色可食部分）
- **直径范围**：新增0.8-2.0厘米直径参数
- **品质分级调整**：
  - 长度分级：调整为5个等级，特级≥30cm
  - 粗度分级：调整为5个等级，特级≥1.6cm

#### 技术需求规格更新
- **测量精度调整**：
  - 长度测量精度：从±2mm调整为±3mm（适应更大尺寸范围）
  - 粗度测量精度：从±1mm调整为±1.5mm（适应更大直径范围）
- **重大调整**：将技术需求拆分为OpenCV图像处理需求和系统需求两部分
  - 创建`opencv_requirements.md`：详细OpenCV算法参数
  - 创建`system_requirements.md`：Android平台、UI、数据管理需求
  - 删除原`technical_requirements.md`

#### 文档优化
- 增加了实际环境参数的详细说明
- 优化了品质分级标准的实用性
- 补充了尺寸比例关系的具体计算

### 数据来源
本次更新基于实际芦笋种植环境的测量数据：
- 物理长度：30-60厘米（完整植株）
- 有效长度：15-35厘米（可食部分）
- 测量环境：田间实际种植条件

### 影响范围
- 用户操作指南中的参照物选择建议
- 品质分级算法的参数设置
- 图像识别算法的尺寸校准
- 结果报告的数据范围显示
