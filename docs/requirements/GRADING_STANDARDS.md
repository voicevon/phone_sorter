# 测量逻辑与分级标准 (GRADING_STANDARDS)

## 1. 测量逻辑
- **标准分辨率**：系统通过 3D 位姿解算实时计算像素到毫米的映射（基于 $Z=8\text{mm}$ 平面假设）。
- **直径测量**：
  - 在**变紫点**上方 20mm 处提取。
  - 若无变紫点（如已被切除），则从**物理底端**上方 20mm 处提取。
- **长度测量**：从鳞芽顶端到变紫点（或物理底端）的物理欧氏距离。

## 2. 分级规格 (Grading Tiers)

| 等级 | 直径区域 (D) | 说明 |
| :--- | :--- | :--- |
| **A 级** | D > 15.0 mm | 特级 |
| **B 级** | 12.0 mm < D ≤ 15.0 mm | 一级 |
| **C 级** | 10.0 mm < D ≤ 12.0 mm | 二级 |
| **D 级** | 8.0 mm < D ≤ 10.0 mm | 三级 |
| **E 级** | 5.0 mm < D ≤ 8.0 mm | 四级 |
| **F 级** | D ≤ 5.0 mm 或 **质量不合格** | 等外/不合格 |

### 2.1 质量不合格判定 (F级直接触发)
符合以下任一条件者，无论直径大小，一律判定为 **F 级**：
1.  **散头/开花**：鳞芽结构松散，明显开花。
2.  **直线度不足**：中轴线偏差 (RMSE) 超过 5.0 mm。
3.  **畸形/怪异**：明显的生长形状异常。

### 2.2 用户可配置性 (Configurability)
- **阈值开放**：系统必须允许用户根据市场需求自行调整各等级的直径范围（如：大笋、中笋、小笋的厘米界限）。
- **配置保存**：调整后的阈值需持久化保存，并即时应用于后续的分拣判定。

## 3. 环境影响因子
- **光照**：需避免强光直射导致的轮廓过曝。
- **背景**：建议使用深色背板，以增强白色/紫色部分的对比度。
