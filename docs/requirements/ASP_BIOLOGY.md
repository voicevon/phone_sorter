# 芦笋生物学特性与测量部位定义 (ASP_BIOLOGY)

## 1. 结构定义
在视觉识别中，我们将芦笋划分为三个关键区域：

1.  **鳞芽 (Head)**: 顶端紧密部分，是长度测量的终点。
2.  **笋体 (Body/Green Stem)**: 绿色茎秆，主要的食用部分。
3.  **紫根 (Purple Root/Butt)**: 茎秆底部由于日照不足或老化呈现紫色/白色的部分。

## 2. 颜色分布特征
- **白色基部**：靠近土壤，质地硬，纤维化。
- **紫色过渡段**：花青素积累形成，通常 2-5cm。
- **绿色顶端段**：光照充足部分，价值最高。

## 3. 测量基准点
- **物理底端**：芦笋的最底部。
- **变紫点 (Transition Point)**：绿色段与紫色/白色段的分界线。
- **标准粗度测量点**：
  - **有变紫点时**：位于**变紫点**向上 **20mm (2cm)** 处。
  - **无变紫点时（如已被切除）**：从**物理底端**向上 **20mm (2cm)** 处测量。
- **长度起点**：通常定义为变紫点或物理底端（视具体需求而定）。

## 4. 特殊形态与分级要求 (不合格品判定)
系统需识别并标记以下“不合格品”：

1.  **散头/开花 (Scattered Head)**：
    - **特征**：鳞芽顶端不紧密，出现过多分叉（开花状）。
    - **判定**：分叉程度超过一定阈值即判定为不合格。
2.  **直线度不足 (Excessive Curvature)**：
    - **特征**：芦笋弯曲度过大。
    - **判定**：偏离中心轴线的最大距离或 RMSE 超过设定阈值即判定为不合格。
3.  **怪异形状 (Deformity)**：
    - **特征**：非典型的生长形状（如扁平、扭曲等）。
    - **判定**：通常难以完全通过算法识别，但在轮廓分析中发现极端比例失调时需标记。
4.  **判定结果**：以上情形均归类为 **F 级 (不合格品)**。
