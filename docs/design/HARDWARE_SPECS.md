# 硬件校准规格 (HARDWARE_SPECS)

系统依赖物理校准板来锚定坐标系并执行透视校正。

## 1. ArUco 标记配置
- **字典类型**：`DICT_4X4_50`
- **标记 ID 与位置**：
  - **ID 10**: 左上 (Top-Left)
  - **ID 13**: 右上 (Top-Right)
  - **ID 40**: 右下 (Bottom-Right)
  - **ID 42**: 左下 (Bottom-Left)

## 2. 物理尺寸
- **核心区域**：167mm (宽) x 250mm (高)。
- **定义方式**：四个标记的中心点围成的矩形区域。

## 3. 安装要求 (3D 自由位姿)
- **非强制正上方**：由于系统采用 3D 位姿估算 (solvePnP)，手机无需严格固定在正上方，支持一定角度的倾斜安装。
- **标记可见性**：四个标记必须在画面中完整可见，且未被芦笋遮挡。
- **稳定性**：安装支架需稳固，避免高频震动导致位姿解算跳动。
