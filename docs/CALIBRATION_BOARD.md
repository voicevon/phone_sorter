# 芦笋分级标定板使用说明 (CALIBRATION_BOARD.md)

为了确保芦笋测量的物理尺寸精确可靠，本系统采用四点透视校正技术。

## 1. 标定板规格

请使用以下源文件按 1:1 比例打印：
*   **文件名**：[aruco_final_10_13_40_42.pdf](resources/aruco_final_10_13_40_42.pdf)

### 标记定义 (ArUco DICT_4X4_50)
| 位置 | 标记 ID | 作用 |
| :--- | :--- | :--- |
| 左上 (Top-Left) | 10 | 建立左上角基准 |
| 右上 (Top-Right) | 13 | 建立右上角基准 |
| 右下 (Bottom-Right) | 40 | 建立右下角基准 |
| 左下 (Bottom-Left) | 42 | 建立左下角基准 |

### 物理距离要求 (精确到 mm)
*   **横向中心距** (Marker 10 ↔ Marker 13): **167 mm**
*   **纵向中心距** (Marker 10 ↔ Marker 42): **250 mm**

## 2. 测量原理

1.  **自动识别**：系统会自动寻找这 4 个特定的 ArUco 标记。
2.  **四点校正 (Homography)**：通过这 4 个点的坐标，系统会计算出透视变换矩阵，消除由于手机拍摄角度倾斜带来的几何畸变。
3.  **标准化映射**：图像会被映射到一个 **10 像素 = 1 毫米** 的标准化画布上。
4.  **合法性校验**：系统会实时监测 4 个标记的相对比例。如果标定板发生折叠、遮挡或打印比例错误（偏差 > 15%），系统将提示“非法标定板”并停止测量，确保分级结果的权威性。

## 3. 使用建议

*   **平整放置**：标定板应贴在平整的桌面上，避免起皱。
*   **全显要求**：拍摄时，确保这 4 个 ArUco 标记完整出现在手机屏幕内。
*   **光照均匀**：避免强烈的反光或过暗的阴影遮挡标记。
