# 系统需求文档 - 芦笋分级系统

## 1. 概述
本系统旨在利用移动设备摄像头和计算机视觉技术，通过识别 ARUCO 标记进行校准，提供以下功能：
1.  **芦笋分级**: 自动化测量芦笋物理尺寸（直径和有效长度）。

## 2. 功能需求

### 2.1 图像采集与校准
- 利用四个 4x4 ARUCO 标记（ID 10, 13, 40, 42）进行空间校准。
- 标记中心需保持固定的 50mm 距离（具体布局见资源文档）。
- 应用透视变换校正，确保获得用于测量的正视图。

### 2.2 芦笋生物结构定义
芦笋分为四个部分（从上至下）：
1.  **鳞芽 (Head)**: 顶端部分。
2.  **笋体 (Body/Green Stem)**: 绿色茎秆部分。
3.  **紫根 (Purple Root/Butt)**: 茎秆底部变紫/变白的部分。
4.  **白根 (White Root)**: 最底部的老化部分（如有）。

### 2.3 测量逻辑 (Measurement Logic)
- **直径测量位置**:
    - **定义**: 测量点位于**绿茎部分的尾部**（即紫根与绿茎的分界点）向上 **20mm (2cm)** 处。
    - **逻辑**: 如果没有检测到紫根，则从物理底端向上 20mm 处测量。
- **有效长度**: 从顶端到紫根起始点的距离。

### 2.4 分级标准
系统根据上述指定位置的直径数据进行分级：
- **A 级**：直径 > 15.0mm
- **B 级**：直径 12.0 - 15.0mm
- **C 级**：直径 10.0 - 12.0mm
- **D 级**：直径 8.0 - 10.0mm
- **E 级**：直径 5.0 - 8.0mm


## 3. 技术规格与参数

### 3.1 ARUCO 标记参数
| 参数 | 取值 | 说明 |
|------|------|------|
| 字典类型 | 4x4 (DICT_4X4_50) | ARUCO 标记使用的字典类型 |
| 标记数量 | 4 个 | 需要检测的标记数量 |
| 标记 ID | 10, 13, 40, 42 | 四个标记的 ID |
| 中心距离 | 50mm | 标记中心之间的参考物理距离 |

### 3.2 测量精度
| 参数 | 允许误差 | 说明 |
|------|------|------|
| 直径精度 | ±0.2mm | 直径测量的最大允许误差 |
| 长度精度 | ±2mm | 长度测量的最大允许误差 |

### 3.3 软件与环境
- **操作系统**: Android 8.0+ (API 26)
- **视觉库**: OpenCV 4.x
- **语音播报**: 系统 TTS (中文)
- **输入分辨率**: 建议最低 1200 万像素
