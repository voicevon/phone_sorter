# 用户操作指南

## 系统简介

芦笋识别测量系统是一款专为Android手机设计的智能应用程序，通过拍照即可快速准确地测量芦笋的有效长度、物理长度和粗度。本指南将详细介绍如何正确使用该系统获得最佳测量效果。

## 使用前准备

### 1. 设备要求
- **操作系统**：Android 7.0或更高版本
- **摄像头**：后置摄像头500万像素以上
- **存储空间**：至少100MB可用存储空间
- **权限设置**：允许应用访问相机和存储权限

### 2. 环境准备
- **光照条件**：
  - 选择自然光线充足的环境
  - 避免强烈直射阳光造成过度阴影
  - 可使用室内均匀散射光
- **背景选择**：
  - 使用纯色背景（白色或浅色最佳）
  - 避免复杂图案和杂物干扰
  - 确保背景与芦笋颜色有明显对比
- **参照物准备**：
  - 准备标准尺寸参照物（如硬币、尺子或专用标尺）
  - 参照物尺寸需在应用中预先设置
  - 建议使用直径为2-3cm的圆形参照物

## 标准操作流程

### 第一步：应用启动与设置
1. **启动应用**：点击应用图标进入系统
2. **首次设置**：
   - 选择测量单位（厘米/英寸）
   - 设置参照物尺寸（输入参照物实际尺寸）
   - 选择精度等级（标准/高精度）
3. **权限确认**：允许相机和存储权限请求

### 第二步：芦笋摆放
1. **摆放位置**：
   - 将芦笋平放在平整表面上
   - 确保芦笋完整展开，无弯曲折叠
   - 白色基部（根部）朝向一侧
2. **参照物放置**：
   - 将参照物放置在芦笋旁边，与芦笋平行
   - 参照物与芦笋间距2-3cm
   - 确保参照物完全进入拍摄画面
3. **角度调整**：
   - 尽量使芦笋与参照物保持平行
   - 避免芦笋过度弯曲或倾斜

### 第三步：拍摄操作
1. **相机准备**：
   - 打开相机功能，进入拍摄界面
   - 观察预览画面，确保芦笋和参照物完整显示
   - 调整手机位置，使摄像头正对芦笋
2. **对焦操作**：
   - 轻触屏幕上的芦笋区域进行对焦
   - 确保图像清晰，边缘锐利
   - 如光线不足，可开启闪光灯补光
3. **拍摄技巧**：
   - 双手持稳手机，避免抖动
   - 保持手机与芦笋平行，减少透视变形
   - 点击拍摄按钮，完成图像采集

### 第四步：识别与测量
1. **自动识别**：
   - 系统将自动识别芦笋轮廓
   - 检测颜色分段（白色、紫色、绿色）
   - 识别参照物并计算比例尺
2. **结果确认**：
   - 查看系统标注的测量线
   - 确认颜色分段识别是否准确
   - 检查参照物识别是否正确
3. **手动调整**：
   - 如识别不准确，可手动调整边界点
   - 拖动控制点修正测量线位置
   - 重新计算测量结果

### 第五步：结果保存与分享
1. **结果查看**：
   - 查看详细测量数据
   - 观察图像上的标注信息
   - 确认数据准确性
2. **数据保存**：
   - 点击保存按钮存储测量结果
   - 可选择保存原始图像或标注图像
   - 设置文件保存位置和命名规则
3. **数据导出**：
   - 导出测量数据为CSV格式
   - 分享测量结果到社交媒体
   - 打印测量报告

## 常见问题解决

### 识别失败处理

#### 问题1：芦笋轮廓识别不准确
**原因分析**：
- 光照不均匀导致阴影过重
- 背景与芦笋颜色相近
- 芦笋摆放不平整

**解决方案**：
- 调整光源位置，使用柔光照明
- 更换对比度更高的背景
- 重新平整摆放芦笋

#### 问题2：颜色分段识别错误
**原因分析**：
- 光照色温影响颜色判断
- 芦笋表面有水珠反光
- 紫色段与绿色段界限模糊

**解决方案**：
- 在自然光下重新拍摄
- 擦干芦笋表面水分
- 手动调整颜色分段边界

#### 问题3：参照物识别失败
**原因分析**：
- 参照物尺寸设置错误
- 参照物被部分遮挡
- 参照物与背景对比度不足

**解决方案**：
- 检查并重新设置参照物尺寸
- 确保参照物完整可见
- 更换对比度更高的背景

### 测量精度提升技巧

#### 1. 拍摄环境优化
- **光线控制**：使用柔光箱或白色反光板补光
- **背景选择**：使用纯白背景布或白纸
- **设备固定**：使用三脚架固定手机，避免抖动

#### 2. 拍摄角度控制
- **垂直拍摄**：尽量保持手机与芦笋垂直
- **平行摆放**：确保芦笋与参照物平行
- **距离控制**：拍摄距离30-50cm最佳

#### 3. 参照物使用技巧
- **标准选择**：使用官方推荐的标准参照物
- **位置固定**：每次放置参照物在同一位置
- **尺寸验证**：定期验证参照物尺寸准确性
