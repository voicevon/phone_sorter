# 用户操作手册 - 芦笋分级系统

## 1. 准备工作
1. **打印标记**：从 `docs/resources/aruco_markers.pdf` 打印包含 4 个 ARUCO 标记的校准板。
2. **硬件布置**：
   - 将标记板固定在平整的工作台面上。
   - 确保各标记中心点的距离满足要求（参考标记板说明，通常为 **50mm**）。
3. **摆放芦笋**：将待测芦笋放置在标记区域内，并尽量与标记边线保持平行。
4. **启动应用**：点击手机上的“芦笋分级”图标，并赋予相机权限。
5. **对准拍摄**：调整手机位置，确保预览画面中完整包含 4 个 ARUCO 标记。
3. **拍照分析**：
   - 点击屏幕下方的红色拍照按钮。
   - 画面定格后，系统将自动进行图像分析。
   - 结果（等级、直径、长度）将显示在屏幕上，并同步进行语音播报。

## 3. 注意事项与故障排查
- **光照环境**：请在光照均匀、充足的环境下使用，避免标记表面产生强反光。
- **识别失败**：若系统提示“未找标记”，请检查标记是否被物理遮挡，或尝试调整拍摄角度以减少畸变。
- **播报无声**：请确认手机系统音量已开启，且系统 TTS 功能正常。

## 4. 常见问题
- **Q: 为什么分级结果显示 F？**
  - A: 说明测得的直径低于 E 级标准（< 0.5mm），请确认拍摄是否清晰，或芦笋是否过细。
- **Q: 需要网络连接吗？**
  - A: 本系统采用本地边缘计算，可在离线状态下正常工作。
