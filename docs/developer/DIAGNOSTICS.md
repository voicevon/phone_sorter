# 诊断预览模式 (DIAGNOSTICS)

应用提供了两种主要的视图模式，用于在不同层级验证系统的准确性。

| 模式 | 显示背景 | 叠加层内容 (Overlay) | 调试目的 |
| :--- | :--- | :--- | :--- |
| **视图 1 (Raw)** | 原始图 (C1) | 无 | 检查原生画面质量、对焦和曝光。 |
| **视图 2 (Analysis)** | 去畸变图 (C2) | 3D 坐标轴、芦笋轮廓、结果 | **核心调试视图**。验证 3D 位姿解算的稳定性及测量准确性。 |

## 调试要点
1.  **3D 坐标轴**：观察画面中的红(X)、绿(Y)、蓝(Z)三轴是否紧贴标定板原点且方向正确。
2.  **测量辅助线**：直径测量线和长度基准线应准确覆盖在去畸变图中的芦笋实体上。
3.  **内参反馈**：若画面边缘出现明显拉伸，需检查内参标定是否生效。

## 操作
在主界面点击“视图切换”图标进行模式切换。
- **推荐做法**：始终使用“视图 2”进行分级，仅在怀疑对焦问题时回退至“视图 1”。
