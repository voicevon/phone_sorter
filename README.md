# 芦笋识别测量系统 - 项目文档

## 项目概述

芦笋识别测量系统是一款专为Android平台开发的移动应用程序，旨在通过智能手机摄像头拍摄芦笋照片，智能识别并测量芦笋的关键参数。该系统利用计算机视觉技术和机器学习算法，能够准确识别芦笋的有效长度、物理长度和粗度，为芦笋品质评估和分级提供科学依据。

## 核心功能

- **智能拍照识别**：通过Android手机摄像头拍摄芦笋照片
- **梯形校正**：自动校正拍摄角度造成的透视变形
- **机型适配**：针对不同Android机型进行摄像头参数校准
- **多参数测量**：
  - 有效长度识别（绿色部分，含部分紫色）
  - 物理长度测量（从头到尾完整长度）
  - 粗度测量（直径或周长计算）
- **参照物校准**：使用标准参照物确保测量精度
- **结果输出**：提供测量数据和可视化标注

## 技术特点

- **Android原生开发**：专为Android系统优化，确保最佳性能
- **实时图像处理**：高效的图像预处理和分析算法
- **机器学习识别**：基于深度学习的芦笋特征识别模型
- **多设备兼容**：适配不同分辨率和摄像头的Android设备
