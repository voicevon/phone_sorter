# Android开发任务指令

## 任务目标
开发芦笋分级系统的Android应用部分

## 技术要求
- Android版本：最低Android 8.0 (API 26)
- 集成OpenCV Android SDK
- 使用系统TTS进行语音播报
- 权限需求：相机、存储、麦克风、网络

## 功能需求
1. 摄像头预览功能
2. 手动拍照功能
3. UI界面设计（开始/结束按钮、预览界面、结果展示）
4. 结果展示（直径、长度、紫根位置、等级）
5. 语音播报功能
6. 与计算机视觉算法的集成
